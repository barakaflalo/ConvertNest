כל ההמרות (תמונות, אודיו, וידאו, מסמכים, טקסט) רצות כולן בדפדפן באמצעות טכנולוגיית WebAssembly ו-Canvas. הקבצים נטענים לזיכרון הזמני של הדפדפן בלבד ונמחקים כשסוגרים את הדף. הם לעולם אינם מועלים לרשת.

לצורך המרות מדיה ומסמכים נטענות ספריות קוד פתוח מרשתות CDN ציבוריות (למשל ffmpeg.wasm, pdf.js). אלו קבצי קוד בלבד — הקבצים שלך אינם נשלחים אליהן.

🔒 In short: every file conversion in ConvertNest runs locally, inside your browser. Your files are never sent to any server and never leave your device.

1. What we collect

Nothing. No sign-up, no account, no tracking, no analytics, no ads. The app sends no personal data to anyone.

2. File processing

All conversions (images, audio, video, documents, text) run entirely in your browser via WebAssembly and Canvas. Files are held only in temporary browser memory and are discarded when you close the page. They are never uploaded.

3. Local storage

Your settings (language, theme, username, an API key if you enter one, and a basic conversion history) are saved in the browser's localStorage, on your device only. You can clear them anytime from Settings or by clearing site data.

4. AI features (Pro · BYOK)

Optional features like transcription, summary and image description require your own API key (Gemini / OpenAI / Claude). When you use them, the relevant text or audio is sent directly from your browser to the provider you chose — not through us. That use is governed by the provider's own privacy policy. The key is stored on your device only and is never sent to us.

5. Third-party libraries

Media and document conversions load open-source libraries from public CDNs (e.g. ffmpeg.wasm, pdf.js). These are code files only — your files are never sent to them.
